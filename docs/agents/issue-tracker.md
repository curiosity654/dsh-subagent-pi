# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues at
`curiosity654/dsh-subagent-pi`. Use the `gh` CLI for all operations.

Create, read, comment on, label, and close issues with the corresponding
`gh issue` commands. Infer the repository from the Git remote when available;
otherwise pass `--repo curiosity654/dsh-subagent-pi`.

## Pull requests as a triage surface

PRs as a request surface: no.

## Publishing

When a skill says “publish to the issue tracker”, create a GitHub issue.
When a skill says “fetch the relevant ticket”, read the referenced GitHub issue
including its comments and labels.
